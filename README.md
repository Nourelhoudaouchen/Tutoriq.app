# Tutoriq — Daily Multilingual Learning Tools

[![Open Source](https://img.shields.io/badge/open%20source-yes-brightgreen)](https://github.com/Nourelhoudaouchen/Tutoriq.app)
[![Contributions welcome](https://img.shields.io/badge/contributions-welcome-blue)](CONTRIBUTING.md)

**Live site → [tutoriq.app](https://tutoriq.app)**

Tutoriq is a free, open-source daily learning companion for adult language learners. No account needed. No dependencies. Just open the page and start learning.

---

## What's inside

| Feature | Description |
|---------|-------------|
| 📖 **Word of the Day** | A vocabulary word in English, French, and Arabic — new word every day |
| 🎯 **Practice Quiz** | 10 random questions on vocabulary, grammar, IELTS tips, and more |
| ⏱ **Pomodoro Timer** | 25/5/15-minute study sessions with progress dots |
| 🔥 **Daily Streak** | Tracks consecutive days you visit, stored in your browser |

All features are client-side only — your data stays in your browser's `localStorage`.

## Running locally

No build step needed. Just open `index.html` in any modern browser:

```bash
git clone https://github.com/Nourelhoudaouchen/Tutoriq.app.git
cd Tutoriq.app
open index.html   # macOS
# or
xdg-open index.html   # Linux
# or double-click index.html on Windows
```
